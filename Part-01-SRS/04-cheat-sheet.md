# 04 — Cheat Sheet

وقت القراءة: دقيقتين. راجع بيه قبل ما تبدأ التمرين.

| المصطلح | المعنى | مثال |
|---|---|---|
| SRS | وثيقة بتوصف النظام المفروض يعمل إيه | متطلبات متجر E-commerce |
| Purpose | الوثيقة دي عن إيه | توثيق متطلبات المتجر |
| Scope | حدود المشروع | Web Store |
| Out of Scope | اللي مش داخل الإصدار الحالي | Mobile App |
| FR | النظام يعمل إيه | إنشاء Order |
| NFR | بإيه مستوى جودة (قابلة للقياس) | 95% من الطلبات أقل من 500ms |
| Actor | شخص أو نظام بيتفاعل مع النظام | Customer، Payment Gateway |
| Stakeholder | حد ليه مصلحة في المشروع | صاحب المتجر |
| Use Case | سيناريو Actor لتحقيق هدف | Place an Order |
| Main / Alternative / Exception Flow | المسار الطبيعي / البديل / الفشل | بيتم الطلب / COD / المخزون خلص |
| Precondition | شرط لازم يتحقق قبل العملية | العميل عامل Login |
| Business Rule | قاعدة بتحكم الوظيفة | الإلغاء قبل الشحن بس |
| Acceptance Criteria | شروط قبول الـ Feature | Given / When / Then |
| Edge Case | حالة نادرة لازم نفكر فيها | ضغط Place Order مرتين |
| Question Log | أسئلتك للـ Business | المخزون بيتخصم إمتى؟ |
