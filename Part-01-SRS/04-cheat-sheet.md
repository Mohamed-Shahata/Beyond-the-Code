# 04 — Cheat Sheet

> ⏱️ دقيقتين · راجع بيه قبل التمرين

| المصطلح | المعنى | مثال |
|---|---|---|
| **SRS** | وثيقة بتوصف النظام المفروض يعمل إيه | متطلبات متجر E-commerce |
| **Purpose** | الوثيقة دي عن إيه | توثيق متطلبات المتجر |
| **Scope** | حدود المشروع | Web Store |
| **Out of Scope** | اللي مش في الإصدار الحالي | Mobile App |
| **FR** | النظام **يعمل** إيه | إنشاء Order |
| **NFR** | **بإيه جودة** (قابلة للقياس) | 95% < 500ms |
| **Actor** | شخص/نظام بيتفاعل مع النظام | Customer, Payment Gateway |
| **Stakeholder** | حد ليه مصلحة في المشروع | صاحب المتجر |
| **Use Case** | سيناريو Actor لهدف | Place an Order |
| **Main / Alternative / Exception Flow** | الطبيعي / البديل / الفشل | COD / المخزون خلص |
| **Precondition** | شرط قبل العملية | عامل Login |
| **Business Rule** | قاعدة بتحكم الوظيفة | الإلغاء قبل الشحن بس |
| **Acceptance Criteria** | شروط قبول الـ Feature | Given / When / Then |
| **Edge Case** | حالة نادرة لازم نفكر فيها | ضغط Place Order مرتين |
| **Question Log** | أسئلتك للـ Business | المخزون بيتخصم إمتى؟ |
