# 04: Cheat Sheet

Reading time: 2 minutes. Review it before starting the exercise.

| Term | Meaning | Example |
|---|---|---|
| SRS | A document describing what the system should do | Requirements of an E-commerce store |
| Purpose | What the document is about | Documenting the store's requirements |
| Scope | The project's boundaries | Web Store |
| Out of Scope | What is not in the current release | Mobile App |
| FR | What the system does | Create an Order |
| NFR | At what quality level (measurable) | 95% of requests under 500ms |
| Actor | A person or system that interacts with the system | Customer, Payment Gateway |
| Stakeholder | Anyone with an interest in the project | Store owner |
| Use Case | A scenario of an Actor achieving a goal | Place an Order |
| Main / Alternative / Exception Flow | The normal path / a valid alternative / a failure | Order completes / COD / Out of stock |
| Precondition | What must be true before the operation | Customer is logged in |
| Business Rule | A rule governing a function | Cancellation only before shipping |
| Acceptance Criteria | Conditions for accepting a feature | Given / When / Then |
| Edge Case | A rare situation worth planning for | Clicking Place Order twice |
| Question Log | Your questions for the Business | When is stock deducted? |
