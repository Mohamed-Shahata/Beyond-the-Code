# Beyond the Code

[Arabic version (Egyptian) | النسخة العربية](../ar/README.md) | [Home](../README.md)

A series on how to **think** before you write code. Not syntax, but the way of thinking behind building a software system, from the first idea to production.

The content is split into short files, and one running example carries through the whole series: an **E-commerce System**.
